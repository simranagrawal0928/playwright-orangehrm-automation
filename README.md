# OrangeHRM Playwright Automation Framework

## Overview
End-to-end test automation framework for OrangeHRM using Playwright, JavaScript, and Page Object Model.

## Tech Stack
- **Testing Framework:** Playwright Test
- **Language:** JavaScript (Node.js)
- **Pattern:** Page Object Model (POM)
- **Reporting:** HTML Reports, Screenshots, Videos

## Setup

### Prerequisites
- Node.js 16+ installed
- npm installed

### Installation
```bash
npm install
